# Changelog

## October 2026 — Midnight Focus

### New look
- New default theme, **Midnight Focus**: near-black background, one acid-lime accent, clean type, flat cards with hairline borders.
- New minimal egg-outline logo and home-screen icon (no cartoon).
- Navigation uses simple line icons instead of emoji.
- Existing learners on the old dark-blue or cream look are moved to Midnight Focus once. Anyone can switch back in Profile → Theme, and their choice is kept.

### Phone layout
- Bottom tab bar on phones: Home, Ranks, Shop, Badges, Profile and More.
- **More** opens a sheet with Create, Install and (for teachers and parents) Dashboard.
- Slimmer header, two-column topic grid, larger buttons, and space for the iPhone notch and home bar.
- The desktop layout keeps the tab row at the top.

### More grown-up
- The cartoon buddy (egg → chick → owl → wizard → hero → dragon) is replaced by rank tiers: Rookie, Bronze, Silver, Gold, Platinum, Elite.
- Boss names are now Procrastination, The Exam, Distraction, The Glitch, Self-Doubt and Night Before Cram.
- Related wording updated in the shop, Profile, badges, level-up message and guided tour.

### Fixes
- **Blank Dashboard:** teachers and parents opened the app to an empty Dashboard, because it was shown before its code had loaded. It now draws correctly on startup.

### Tooling
- GitHub-ready repository with build, check, split and phone-testing tools.
- Automated tests (29 checks) and an automatic GitHub check on every push.
